## منطق حساب أيام التدقيق

مطابق 100% للحاسبة المرجعية `ISO_CERT_AUDIT_CALCULATOR_WITH_AUDITORS.xlsx`:

1. أيام الأساس حسب شريحة الموظفين (14 شريحة: 1-5 ← 1.5 يوم … 1176-1550 ← 14 يوم) × عدد المواصفات
2. خصم **MD5** حتى 20% (يدخله المراجع) — خصم **MD9** ثابت 20% لـ ISO 13485 — خصم **MD11** للتكامل 20% (أكثر من مواصفة + Integrated)
3. تقريب لأقرب نصف يوم
4. التوزيع: Stage 1 = 30% · Stage 2 = 70% · المراقبة = ⅓ · إعادة الاعتماد = ⅔

**حالة قبول مُختبرة:** 10 موظفين، 3 مواصفات متكاملة ← أساس 6 ← ‎−20% MD11 ← 4.8 ← **5 أيام** (S1=1.5, S2=3.5, SUR=1.5, RC=3.5) ✓

## قاعدة البيانات

20 جدولاً مع RLS + Storage bucket (`client-files`) — انظر [supabase/schema.sql](supabase/schema.sql).

**البيانات المزروعة:** 6 مواصفات، 10 أكواد IAF، 14 شريحة حساب، **19 مدققاً حقيقياً** باعتماداتهم، عوامل الخصم الثلاثة، 8 عملاء (منهم WRASS REAL ESTATES بملفها الفعلي الكامل: الحساب، Stage 1/2، تقريرا عدم المطابقة المغلقان، برنامج 3 سنوات)، 15 تدقيقاً، 8 تقارير NC، حجوزات مدققين، سجل أنشطة وإشعارات.

### النقل لمشروع Supabase آخر

1. من لوحة Supabase → SQL Editor: نفّذ `supabase/schema.sql` ثم `supabase/seed.sql`
2. حدّث `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY` في `.env.local`

## تفعيل الذكاء الاصطناعي الكامل

الإعدادات ← مفتاح Claude API ← الصق مفتاحاً من [console.anthropic.com](https://console.anthropic.com) ← حفظ.
بدون مفتاح يعمل المساعد بوضع محلي (إحصائيات/حساب/بحث/إضافة بتأكيد). مع المفتاح: فهم لغة حرة + 6 أدوات تنفيذ (بحث، إحصائيات، حساب، فحص مدقق، إضافة عميل، إنشاء NC) مع طلب تأكيد قبل أي تعديل بيانات.
